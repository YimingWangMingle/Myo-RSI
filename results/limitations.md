# Limitations and run notes

- The local runtime uses NVIDIA RTX 4060 (8,188 MiB), Python 3.13.17, PyTorch 2.14.1+cu130, MyoSuite 3.1.0, mjlab 1.6.1, RSL-RL 5.4.2 and MuJoCo / MuJoCo Warp 3.11.0. The mjlab package pins the 3.11 series. MyoSuite warns that some hand tendon paths on this Warp version can differ from CPU MuJoCo by up to about 3 mm. Training and policy evaluation both use CUDA. [Upstream tendon issue](https://github.com/google-deepmind/mujoco_warp/issues/1713)
- Uniform tolerance across observation channels failed on CUDA. The first check is archived in `diagnostics/initial_uniform_tolerance.json`. The subsequent probe uses 0.5° for joint angles, pose error and angular velocity multiplied by control timestep, 1 mm for tip position/error and 0.00002 for muscle activation. This was a protocol refinement after inspecting P0 and before inspecting PPO performance. Seeds 709 and 719 independently exercised complete repeated episodes. Read `preflight.json` for actual differences and terminal outcomes. Longer closed-loop trajectories may diverge on the GPU. [mjlab reproducibility notes](https://mujocolab.github.io/mjlab/v1.6.0/source/faq.html)
- The official two-iteration smoke used 32 environments and seed 11. A CLI parse failure and a first attempt using the bare RSL runner stopped before any training interactions. The experiment uses mjlab's official runner, which adapts the task config to RSL. Timings in the main ledger describe the single-device training/evaluation jobs. Package downloads, environment setup, shader compilation before training and time spent writing the implementation are outside the training budget. Diagnostic timings absent from the logs are left blank.
- Success is the native final-step criterion. The evaluation cohort uses one explicit reset seed per lane and the first completed episode. The curves use separate validation seeds. A and B share the same downstream interaction budget for each objective. Source training, NMF fitting, evaluation and adaptation have separate ledger entries. No separate rollouts were purchased for bank collection.
- The three seeds support a preliminary comparison. The B seed SD is conditional on the single shared bank. Independent bank-fitting replicates were outside this experiment. The selected bank size, 16-unit residual and finite training budget are engineering choices. A seed-level SD describes training variability. Episode-level Wilson intervals describe the uncertainty of each individual policy's held-out success proportion.
